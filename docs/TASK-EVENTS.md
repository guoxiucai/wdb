# 任务事件推送

本次增加任务状态和已有任务 stdout/stderr 的 SSE 订阅，复用 HTTPS 端口与原有 Bearer 授权、证书指纹和任务归属校验。无需新 npm 运行依赖。未增加交互式 shell、持续日志后端、端口转发或 WSS。

## 接口

`GET /v1/health` 返回 `data.taskEvents:true`；未声明此字段的服务端继续使用任务查询接口。

`GET /v1/tasks/<id>/events` 返回 `text/event-stream; charset=utf-8`。订阅只允许访问当前授权客户端拥有的任务。每个客户端最多同时订阅 16 条事件流。

- `task` 事件的 `data` 是与 `GET /v1/tasks/<id>` 相同结构的 JSON 信封。订阅时发送当前快照，之后推送状态变化；终态发送后结束响应。
- 可选查询参数 `stdoutOffset` / `stderrOffset` 是非负安全整数字节偏移。提供参数才订阅对应输出，从该偏移补发已有 `.live` 文件内容，再发送新增内容。
- `output` 事件的 `data` 包含 `deviceId`、`taskId`、`stream`、`offset`、`base64`；每块原始数据最多 48 KiB。字节偏移配合客户端增量 UTF-8 解码，避免多字节字符跨块损坏。文件上传下载仍是原始二进制流。
- 已有输出在对应任务快照/终态之前发送，保证客户端收到终态时已经收齐订阅的保留输出。只回放现存输出与最新状态，不维护无限事件历史；客户端重连通过字节偏移恢复，而非 `Last-Event-ID`。
- SSE 注释保活每秒发送，不代表客户端输入控制心跳，也不延长临时授权。流内授权失效以 `error` 事件返回错误信封，随后结束；撤销、断开与服务关闭会清理订阅。

慢客户端使输出读取暂停，等响应 `drain` 后继续从已有输出文件读取；不另建无界输出队列。单事件上限 32 MiB；长时间无法传输时关闭订阅，由客户端按原任务恢复。

服务端自身的输出回调直接通知订阅；桌面助手在另一个进程写入 `.live` 文件时，通过任务目录的文件变更通知触发推送。两条路径共用字节偏移，避免重复发送。停止订阅时同时释放文件监听器。

## 兼容与验证

接口是 `/v1` 的可选能力。旧 CLI 不受影响；新 CLI 连接旧服务端自动轮询，连续断流三次也会回退轮询。恢复、超时、JSON 输出以及取消语义见 [RECONNECTION.md](RECONNECTION.md)。

`npm run test:client` 包含 `tests/transport-events.test.js`，测试使用临时生成的证书和本地真实 HTTPS Bridge，不读取 Windows 服务私钥。覆盖连接复用与隔离、证书替换、推送完成、UTF-8 断流续接、旧版回退、超时、授权和归属隔离、服务重启以及输出背压。
