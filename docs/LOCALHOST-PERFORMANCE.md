# Windows localhost 文件传输实测

运行时间：2026-11-05 22:21:30 至 2026-11-05 22:22:21（北京时间，UTC+08:00）。测试代码：`node scripts/validate-transfer.js`。

环境：Windows 11 Pro 10.0.28000 x64；Intel(R) Core(TM) i7-14700，28逻辑处理器；内存 31.8 GiB；Node v24.15.0；服务端 0.1.0。生成前数据盘可用 914.9 GiB。物理磁盘：KINGSTON SNV3S1000G（1 TB NVMe SSD）和 SAMSUNG MZVL4256HBJD-00BH1（256 GB NVMe SSD）；Ethernet 处于断开状态，Wi-Fi 链路速率 866.5 Mbps。本测试不经过这两种网络接口。

客户端和服务端位于同一台设备，文件位于同一数据盘，测试期间可能与 1080p 录像并行。结果只用于验证 localhost 流式传输、64 位文件大小和完整性，不作为千兆局域网 ≥80 MB/s 单项验收。

每个文件均逐块生成密码学随机数据。生成时计算 SHA-256；push 前单独完整读取校验，服务端接收时流式校验；pull 等待服务端预先计算校验值，接收时流式校验；下载后再次独立读取整个文件计算 SHA-256，四个哈希一致。完成后清理生成、上传、下载三个大文件，保留此报告和忽略目录中的机器可读记录。

push 传输时间包含 TLS 请求及服务端确认，服务端 SHA-256 在接收过程中计算。pull 响应等待包含 TLS 和服务端预校验；pull 传输计时从收到响应头至文件流结束，SHA-256 同步计算。总耗时包含各阶段和正式文件发布。MB/s 使用十进制 1 MB = 1,000,000 bytes。随机数据生成和独立复核不计入传输总耗时。

较小文件为 1 GiB（满足至少 1 GB 的数据规模），较大文件为 4 GiB + 17 bytes（超过 32 位无符号文件大小边界）。中文及空格路径均参与本次上传和下载。目录递归、默认不覆盖、错误校验清理和断线生命周期另见 CLI 集成测试。
