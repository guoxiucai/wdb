## 操作规则

- CDP 连接目标是服务端本机回环端口，不是 CLI 所在电脑；只允许明确的本机端点，不扫描局域网或任意应用端口。
- 多个页面必须明确 target ID；控件匹配多个必须明确选择。CDP 的 CSS 视口坐标与 Windows 物理桌面像素分开标识。
- 联合观察同时返回 CDP、UIA 的可用性与错误，并保留桌面截图。视觉理解由 Agent 完成，WDB 接收经观察选定的坐标；不内置未经说明的图像识别模型。
- `auto` 只在可确认尚未执行操作的定位/通道不可用错误时换通道。调用已发出后超时、断线或操作后观察失败，必须保留“结果未知”，不得重复点击。
- CDP 触发不算 UIA 通过，也不算 Windows 实体输入或多指触摸通过。安装/启动/观察/操作与状态验证分别留证。
- 自研配置说明覆盖调试启动开关、辅助功能、语义控件和稳定测试定位标识；不要求关闭 sandbox、contextIsolation 或开启 nodeIntegration。
