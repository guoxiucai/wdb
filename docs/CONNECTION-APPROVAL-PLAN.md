# 首次连接服务端确认

1. 新增服务端配对审批状态和授权生命周期：通过桌面助手获取本地决定；新客户端仅在同意后得到令牌。记住授权持久保存；临时授权在主动断开、服务重启或30分钟无请求后失效。现有授权保持。单元测试覆盖拒绝、超时、断线、并发、过期、重启与持久化，通过后提交。
2. 实现 Windows 本地同意/拒绝/记住对话框、倒计时和取消；CLI 等待服务器决定并返回明确结果。编译，验证桌面助手链路和客户端结果后提交。
3. 部署本机、更新服务端/客户端包、Skill与Mac协议文档。真实授权弹窗由本机操作者决定，记录人工验证和自动测试边界，完成后提交并同步仓库。

2026-11-06 需求修订：首连直接 `wdb connect <IP>`，取消手工指纹/配对码前置条件。客户端自动发现并固定首次证书，服务端本地同意后保存身份；已有指纹变化仍失败。先验证协议与 CLI，再部署本机和更新两端文档/交付包，每阶段验证后提交。修订取代早期保留人工配对材料的方案。

未勾选记住时是临时逻辑连接，不等于单条HTTP请求；默认记住未勾选。拒绝不建立授权或持久拒绝名单。确认有效期120秒，客户端默认等待150秒，不自动重复配对。新配对不能在没有可用交互桌面时自动通过；既有记住的授权可执行原有后台能力。
