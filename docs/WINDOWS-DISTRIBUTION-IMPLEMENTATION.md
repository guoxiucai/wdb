# Windows 分发实施与验证计划

基线：2026-11-06，远端 `41f00e4`。本轮仅在 Windows 开发机构建、安装和验证，不发布 npm 或上传发行文件。

1. 部署并验证 SSE：真实 SCM 服务、交互助手及 SYSTEM shell；输出及时推送、UTF-8、断流续接、等待超时、取消、服务重启不重跑。保留可复现脚本和脱敏报告，通过后提交。
2. 统一纯 JS npm 客户端：运行时检查、版本单一来源、白名单打包、隔离 prefix 安装、中文/空格路径、更新/卸载保留凭据。通过后提交。
3. 双运行时服务 payload：依赖锁定、受保护外部 Node 检测和绑定、发行模式禁止现场编译、预检/恢复/诊断及防火墙绑定。通过后提交。
4. 双 EXE 与签名阶段：同一公共 payload 派生 with-node / external-node；Prepare、Package、Finalize；开发包明确未签名；人工签名清单和冻结内容验证。通过后提交。
5. 本机安装闭环：旧目录升级、两模式切换/升级、卸载重装和失败恢复；从 npm 安装产物执行文件/截图/录屏/SSE，记录产物大小与 SHA-256，完成文档并提交。

缺少正式包名、项目许可、发布者和签名证书不阻塞开发测试；占位参数只能生成开发包。真实 Mac、干净 Windows、真实证书签名及 registry 验收必须单列为未执行，不能用本机测试替代。
